Current Voltage Sensor

The Problem

The car needed a way to measure current and voltage inline with the main battery pack, up to ±150A bidirectional and 0–15V, without adding meaningful size or complexity to the high-current path. This was assigned as my first major PCB project, so on top of the electrical requirements, it was also where I learned the actual Altium workflow from close to zero.

Requirements

ID Requirement Status
ELEC-1 Sense bidirectional current up to ±150A on the main battery line Met
ELEC-2 Sense bus voltage over a 0–15V range Met
ELEC-3 Self-powered directly from the bus, no external supply Met
ELEC-4 The board shall have a compact footprint Met
ELEC-5 High-current path handled externally via wiring to the car's existing XT90 connectors, not routed through PCB copper Met

Design Decisions

Hall Effect/Shunt

Current sensing uses an Allegro ACS758KCB-150B Hall effect sensor with an RC output filter, rather than a shunt-based approach. Avoiding the extra power dissipation and insertion loss a shunt would add directly in the main battery line.

Op-Amp UGB

Voltage sensing uses a resistor divider feeding an op-amp buffer (MCP6001) in unity-gain configuration, so the divider isn't loaded down by whatever's reading the signal downstream.

LDO/Buck Trade

The board is self-powered directly from the bus rather than needing an external supply. A TPS5430 buck converter was designed in initially, then removed after the power dissipation math showed a simple LM1117-5.0 LDO was sufficient. Calulcations revealeed around 160mW dissipation, which was well within reason without the added complexity of a switching regulator.

High Current Flow

150A can't reasonably flow through PCB copper without excessive trace width, so the actual high-current connection is handled through external wiring to the car's existing XT90 connectors rather than an on-board connector — keeping the board small and avoiding a high-current connector footprint it doesn't need.

Challenges

Learning Altium Software

This was my first major PCB, and I started layout knowing Altium's schematic side but close to nothing about layout. Things like polygon pours, DRC rules, and via/copper practices were all things I learned by hitting them directly on this board rather than in a tutorial first.

Oversized Connectors

The original low-current connectors (Molex-style WR-MPC3) got flagged during review and were replaced with JST PH 2.0mm through-hole vertical connectors for the power tap input and signal output. This was a straightforward swap, but one that meant re-checking footprint and board-size impact rather than just dropping in a new part.

Maintaing Compact Board Size

Reviewer feedback throughout layout had to be weighed against a hard constraint: any change that grew the board footprint was out, since compact size was the whole point of this board sitting inline with existing wiring. That meant some layout fixes had to be solved within the existing footprint rather than by simply giving a cramped section more room.

Status

The team decided to go with an off-the-shelf Hall effect sensor rather than a custom shunt-based measurement circuit. Connector selections and the board layout are finalized.
